# Data card

Every record used by SabiID is synthetic and generated by
`backend/data_gen.py`. No real person's data is used anywhere.

## How it is made

- **Seed.** A fixed seed (`20260921`) so the same run reproduces the same data.
- **Names.** Common Nigerian given names and surnames from two fixed lists, drawn
  at random and combined as `given middle surname`. Any resemblance to a real
  person is coincidental and unintended.
- **NIN.** The string `NIN` followed by 11 random digits. Real NINs are 11 digits
  with no prefix, so these cannot collide with a real one.
- **BVN.** The string `BVN` followed by 11 random digits. Same reasoning.
- **Dates of birth.** Random. Four citizens are forced into 2009 to 2015 so there
  are clear minors for the age check. One is forced into the late 1950s as a
  pensioner.
- **State of residence.** Random from twelve Nigerian states.
- **Phone numbers.** Random `+234` numbers. Only a hash is ever stored, never the
  number.

## Files written

| File | Contents |
|---|---|
| `data/synthetic_citizens.json` | 48 citizens, full plaintext, each flagged `"synthetic": true`. |
| `data/sources/nimc.json` | Mock NIMC: NIN to name, date of birth, state. |
| `data/sources/nibss.json` | Mock NIBSS: BVN to name, date of birth, phone hash. |
| `data/sources/civil_registry.json` | Mock Civil Registration service: one deceased record. |
| `data/sabiid.db` | SQLite. Enrolled credentials, partners, payroll roster, the log. |

## Deliberate imperfections

Placed by citizen index so the demo can show honest failure, not just success:

- **Index 12.** Same person, name written in a different order at NIBSS
  (`given middle surname` becomes `middle given surname`). Trips the NIN and BVN
  name consistency check, and would trip an exact name match.
- **Index 13.** An accent present at NIMC and dropped at NIBSS
  (`Bọlanle` against `Bolanle`). Same effect.
- **Index 14.** A one-year typo in the BVN date of birth. Lowers the confidence
  score without failing the name check.
- **Index 20.** NIN only, never completed BVN enrolment. Shows the
  single-identifier path and its lower confidence.

## Payroll roster

Twelve lines for one synthetic ministry:

| Lines | Ground truth | Expected outcome |
|---|---|---|
| 7 | active real staff | released |
| 1 | relocated, stops answering | held after a missed check |
| 1 | real staff, out of network signal this cycle | held (a false hold, the honest cost) |
| 1 | deceased, in the Civil Registration service | held, caught before waiting for a phone |
| 1 | a wrong person answers with a non-matching sample | held, flagged as possible impersonation |
| 1 | fabricated, NIN not in NIMC | held, never a real person |
